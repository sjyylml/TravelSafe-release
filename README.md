# 旅安 TravelSafe — 安装包发布页

给中国自由行游客的「出境应急大脑」：出发前给你一页纸，在现场给你一张卡，没网也能用。

> 本仓库仅发布安装包（APK），源代码在私有仓库维护。

## 安装说明

1. 扫码或点直链下载 APK（约 18 MB）
2. 打开下载的文件，系统提示「未知来源」时选择**允许本次安装**
3. 微信内扫码如无法直接下载，请点右上角「···」→ 用浏览器打开
4. 从 v0.1.0 升级：直接覆盖安装即可

要求：Android 8.0（API 26）及以上。当前为 debug 签名测试版，正式上架前会更换签名。

## 版本内容

### v0.2.0（当前）

- 目的地选择：首批 10 国列表，本期开放泰国
- 现场救场卡：海关/打车/医院/报警/酒店/退税六场景 × 三件套（三步操作 / 中英泰短句大字卡 / 留证清单）
- 离线SOS：泰国紧急电话一键拨号、GPS 坐标 + 短信发送、紧急句子卡
- 证件加密相册：AES-256 本地加密 + 生物识别门禁，数据不出设备

### v0.1.0

- 三按钮首页（行前风险包 / 现场救场卡 / 离线SOS包）+ 导航骨架
